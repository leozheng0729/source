주석 스크린샷으로 웹사이트 버그를 보고하려면?

문제가 발생한 정확한 위치를 보여주세요.

Chrome에 추가 ↗

어떻게 사용하나요?

  1. 문제가 있는 페이지를 열고 표시 영역에서 오류를 재현하세요.
  2. 화살표로 위치를 가리키고 기대 동작과 실제 동작을 텍스트로 설명하세요.
  3. 화면을 캡처하세요. Pro는 워터마크 없는 PNG 또는 PDF와 Markdown 피드백 목록을 내보냅니다.

시작 전에 알아둘 제한은?

무료와 Pro는 어떻게 다른가요?

무료는 주석 도구, 페이지당 총 20개 주석, 워터마크가 있는 일반 스크린샷을 제공합니다. Pro는 개수와 워터마크 제한을 없애고 HD PNG, PDF, Markdown 피드백, 로컬 기록, 출처 정보를 추가합니다.

PDF에 웹페이지 전체가 포함되나요?

아니요. Pro는 현재 보이는 영역의 스크린샷을 PDF로 내보냅니다. 스크롤 페이지 전체를 이어 붙이거나 선택 가능한 웹 텍스트를 보존하지 않습니다.
