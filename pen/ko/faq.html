Highlighter Pen은 무엇인가요?

Highlighter Pen은 웹페이지에 강조 표시, 그림, 화살표, 메모, 텍스트 상자를 추가하는 Chrome 확장 프로그램입니다. 읽기, 웹사이트 검토, 버그 보고, 피드백 공유에 유용합니다.

무료와 Pro는 어떻게 다른가요?

무료는 주석 도구, 페이지당 총 20개 주석, 워터마크가 있는 일반 스크린샷을 제공합니다. Pro는 개수와 워터마크 제한을 없애고 HD PNG, PDF, Markdown 피드백, 로컬 기록, 출처 정보를 추가합니다.

새로고침해도 주석이 남나요?

Pro는 이 브라우저에 주석을 로컬 저장하고 같은 URL에서 복원합니다. 기기 간 동기화는 지원하지 않습니다. 사이트 변경으로 복원이 영향을 받을 수 있으니 중요한 내용은 내보내 백업하세요.

3배 HD 스크린샷이란 무엇인가요?

Pro는 보이는 영역을 기기 기본 해상도로 캡처하고 필요한 경우에만 CSS 픽셀당 이미지 픽셀이 최소 3개가 되도록 확대합니다. 확대해도 원본에 없는 세부 정보가 생기지는 않습니다.

PDF에 웹페이지 전체가 포함되나요?

아니요. Pro는 현재 보이는 영역의 스크린샷을 PDF로 내보냅니다. 스크롤 페이지 전체를 이어 붙이거나 선택 가능한 웹 텍스트를 보존하지 않습니다.

Pro는 구독인가요? 어떻게 활성화하나요?

현재 Pro는 9.99 USD 일회성 결제입니다. 로그인 후 같은 이메일로 결제하고 확장 프로그램의 Pro 페이지에서 결제 상태를 새로고침하세요. 최종 금액과 적용 세금은 결제 화면에 표시됩니다.

주석이 클라우드로 업로드되나요?

주석과 내보내기 파일은 로컬에서 처리됩니다. 계정과 결제 확인에는 Supabase, 선택 시 Google 로그인, Stripe가 사용됩니다. 자세한 내용은 개인정보 처리방침을 확인하세요.
