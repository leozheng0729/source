웹사이트에서 직접 디자인 피드백을 주려면?

레이아웃, 간격 또는 문구 옆에 의견을 배치하세요.

Chrome에 추가 ↗

어떻게 사용하나요?

  1. 검토할 창 크기로 페이지를 여세요.
  2. 화살표와 번호 메모를 추가하고 메모 하나에 변경 하나를 담으세요.
  3. 표시된 검토 화면을 내보내세요. Pro는 HD PNG와 표시 영역 PDF도 지원하며 평소 협업 도구로 파일을 공유할 수 있습니다.

시작 전에 알아둘 제한은?

무료와 Pro는 어떻게 다른가요?

무료는 주석 도구, 페이지당 총 20개 주석, 워터마크가 있는 일반 스크린샷을 제공합니다. Pro는 개수와 워터마크 제한을 없애고 HD PNG, PDF, Markdown 피드백, 로컬 기록, 출처 정보를 추가합니다.

3배 HD 스크린샷이란 무엇인가요?

Pro는 보이는 영역을 기기 기본 해상도로 캡처하고 필요한 경우에만 CSS 픽셀당 이미지 픽셀이 최소 3개가 되도록 확대합니다. 확대해도 원본에 없는 세부 정보가 생기지는 않습니다.
