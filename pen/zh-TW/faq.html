Highlighter Pen 是什麼？

Highlighter Pen 是 Chrome 網頁註記擴充功能，支援螢光標記、畫筆、箭頭、便條和文字方塊，適用於閱讀記錄、網站審查、問題回報及意見分享。

哪些功能免費，哪些需要 Pro？

免費版提供註記工具，每頁各類註記合計最多 20 個，一般截圖含浮水印。Pro 取消數量及浮水印限制，並提供高畫質 PNG、PDF、Markdown 意見清單、本機歷史記錄及自訂來源資訊。

重新整理網頁後，註記還會保留嗎？

Pro 將註記儲存在目前瀏覽器本機，返回相同 URL 時自動還原，不支援跨裝置同步。網站內容變動可能影響還原，建議匯出重要內容備份。

3 倍高畫質截圖是什麼意思？

Pro 優先以瀏覽器原生裝置解析度擷取可見頁面，僅在必要時放大至每個 CSS 像素至少對應 3 個影像像素。放大不會產生原圖沒有的細節。

PDF 匯出會包含整個網頁嗎？

不會。Pro 將目前可見的網頁區域截圖匯出為 PDF，不會拼接整張捲動網頁，也不會保留可選取的網頁文字。
